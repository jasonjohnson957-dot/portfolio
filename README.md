## How I build

Content quality is a process problem, so I treat it like one.

- **Three-pass QA:** mechanical, then functional, then content
- **Mandatory re-check pass** after every fix round, because fixes create bugs
- **Paired outputs kept in surgical sync:** HTML, LaTeX, and PDF never drift
- **Programmatic evaluation** across content accuracy, code correctness, narrative continuity, and job-readiness
- Every claim traceable to a framework, statute, or peer-reviewed source
